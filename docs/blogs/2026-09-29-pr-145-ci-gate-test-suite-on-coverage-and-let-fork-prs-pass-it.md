# ci: Gate Test Suite on coverage and let fork PRs pass it

- **Release tag:** `v0.0.2`
- **Source PR:** [#145](https://github.com/mpaulosky/IssueTracker/pull/145)

## PR description

### Summary

Fixes two regressions that Copilot's review of #140 found in the new `ci.yml`:

- **The coverage gate wasn't enforced.** `Test Suite`, the required check, didn't wait for `Coverage Analysis`, so a PR under 60% coverage could merge. The retired `suite-gate` job enforced it. `Test Suite` now needs `coverage` and fails when it fails or is cancelled. The coverage result also appears in the job summary.
- **Fork PRs were blocked.** Fork PRs get a read-only `GITHUB_TOKEN`, so the test-report publish step failed inside the required job. It now skips forks, as it already skipped Dependabot. The status step still fails the job on any failed test.

The other #140 findings are tracked in #144 (release ordering, pre-commit staging, per-project rebuilds) and in the upcoming agent-guidance PR (MD041 vs. the H2 convention).
