### What changed

**Apply** (`chore: Apply repo-ci-baseline Template`, the script's output alone; 12 Owned files added, 24 overwritten, 2 Seed files written):
- **One written PR process:** `docs/PROCESS.md`, a PR template, and a **PR title** check (`pr-title.yml`, `check-pr-title.sh`).
- **Branch names are checked in CI** as well as in `pre-push` (`check-branch-name.sh`).
- **Worktrees:** `pre-commit` refuses commits in the main checkout; every change goes in a worktree under `../IssueTracker-worktrees/`.
- **Auto-merge:** a 3-round cap on Copilot's reviews and the `sandcastle:needs-human` hand-back. #201's re-check on a submitted review is kept: the Template carries it.
- **Test discovery:** `discover_tests.py` resolves `IsTestProject` through `Directory.Build.props` and Conditions, and the pre-push gate uses it too, so `TestingSupport.Library` is never run as a test project.
- **Releases:** Dependabot bumps fold into the next Release; the CI summary names a docs-only skip.
- **Seeds written:** `.github/ci/coverage-threshold` and `.github/ci/gate-checks.sh`.
- **Smaller changes:** `.gitignore` additions, `load_test_env.py`, the hook and release fixes, and the lint config updates.

**Adapt:**
- `CLAUDE.md`'s Workflow section points at `docs/PROCESS.md`.
- `docs/CONTRIBUTING.md` points at `PROCESS.md` for branches, commits and review. It also fixes content that was wrong for this repo: links to `BlazorBlogApp`, a `develop` branch, and a SQL / EF Core / WASM description and folder tree. These now match `CLAUDE.md` and link `project-structure.md` and `architecture.md`.
- `dependabot.yml`: the `chore(deps)` commit prefix for all three ecosystems.

**GitHub settings** (`github-settings.sh --fix`, first pass, already applied):
- squash only, with PR title + body as the commit; read-only Actions token;
- pinned actions required;
- the ruleset targets the default branch, has no bypass actor, drops `code_quality`, and requires `markdownlint`, `yamllint`, `actionlint`, `shellcheck` and `zizmor`;
- Copilot reviews drafts;
- `docs-only` and `sandcastle:needs-human` labels created.

The second pass, right after this merges, adds **Branch name** and **PR title** to the required checks.
