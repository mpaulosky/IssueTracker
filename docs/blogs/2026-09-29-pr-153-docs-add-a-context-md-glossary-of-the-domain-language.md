# docs: Add a CONTEXT.md glossary of the domain language

- **Release tag:** `v0.0.5`
- **Source PR:** [#153](https://github.com/mpaulosky/IssueTracker/pull/153)

## PR description

### What

Adds `CONTEXT.md` at the repo root: a glossary of the IssueTracker domain language (people, issues, comments and record keeping). Each term has a short definition and the synonyms to avoid.

### Why

Gives docs, issues and code one shared vocabulary. It settles three overloaded terms:

- The **"Answered" Status is now "Accepted"**, so it isn't confused with a Comment picked as an Issue's **Answer**.
- **Approval** means an Issue becomes visible to every User; it doesn't mean the change ships in a release.
- **Rejection** is final.

The code still uses some of the old names (seed data, the internal `Enums.Status`, `ApprovedForRelease`). #152 tracks aligning it.
