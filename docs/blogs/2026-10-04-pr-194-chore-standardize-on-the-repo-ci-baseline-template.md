# chore: standardize on the repo-ci-baseline Template

- **Release tag:** `v0.0.23`
- **Source PR:** [#194](https://github.com/mpaulosky/IssueTracker/pull/194)

## PR description

Brings IssueTracker onto the shared CI, release and hook Baseline by Applying the `repo-ci-baseline` Template from dotfiles, then adapting the repo to it.

### What changed

- **Apply** (`chore: apply repo-ci-baseline Template`): the script's output, unchanged. 35 of the Template's files were already identical.
  - `ci.yml` runs tests on Microsoft Testing Platform, and calls `.github/ci/prepare.sh` in place of the hard-coded AppHost step.
  - `global.json` moves to SDK 10.0.401 (`rollForward: latestMinor`) and turns on the MTP test runner.
  - New files: `GitVersion.yml`, `.claude/skills/README.md` and `.github/ci/prepare.sh`. `.gitignore` also ignores `.directory`.
- **Tests on xUnit v3 / MTP.** `global.json`'s MTP runner refuses VSTest projects, so all nine test projects move from xUnit v2 to `xunit.v3` with `Microsoft.Testing.Extensions.CodeCoverage`.
  - `IAsyncLifetime` returns `ValueTask`.
  - Calls that take a token get `TestContext.Current.CancellationToken` (analyzer rule xUnit1051).
  - `dotnet.config` and `runsettings.xml` are removed.
- **`prepare.sh`** carries IssueTracker's own CI setup: it sets `ConnectionStrings__mongodb` for every test job and, before `AppHost.Tests`, publishes the UI and pulls Mongo and Redis.
- **Template fixes from mpaulosky/dotfiles#14**, re-applied here:
  - `gate.sh` tests only projects marked `IsTestProject`. Before, the gate failed on `TestingSupport.Library`.
  - `GitVersion.yml`'s bump-message regexes have single backslashes, so they match the `+semver:` markers. Copilot found this in its review.
  - The Template no longer carries `.claude/settings.json`: Claude Code permissions are set per user. The first Apply had added it, so this PR removes it.
- **Docs.**
  - CLAUDE.md no longer pins the SDK to 10.0.3xx. The "4xx can't compile Razor" errors came from a stale build server, and the UI builds cleanly on 10.0.401 after `dotnet build-server shutdown`.
  - CLAUDE.md now describes xUnit v3 on MTP.
  - `docs/testing.md` uses MTP's `--coverage` and uploads the Cobertura file it writes, and `docs/project-structure.md` drops the removed files.

### Checks

- All nine projects pass with `ci.yml`'s exact command: **483 tests**, the same count per project as `main` under VSTest. Each project writes its TRX and Cobertura files.
- The pre-push gate passed on the pushed commit, with a clean `-warnaserror` build and every test project.
- `release_queue.py` prints `[]` with v0.0.22 as the cutoff, and no Release is missing a blog post.
- No GitHub settings change: the required checks are still `Build Solution` and `Test Suite`, and the `semver:*` labels and `RELEASE_PR_PAT` already exist.
