# ci: Run code metrics by hand and drop unused Auth0 settings

- **Release tag:** `v0.0.4`
- **Source PR:** [#148](https://github.com/mpaulosky/IssueTracker/pull/148)

## PR description

### Summary

- **Code metrics run by hand only.** The pinned metrics action doesn't count members of classes declared with a primary constructor. All 11 services and repositories in `src/` use one, so the reports show them as empty. `code-metrics.yml` now runs on `workflow_dispatch` only, as in atelier-store, and I've removed the misleading root `CODE_METRICS.md` that #142 added (nothing linked to it). This corrects my earlier statement on #140 that IssueTracker had no primary constructors.
- **Unused Auth0 settings removed.** The test job set `Auth0__*`, `Auth0Management__*` and `Parameters__auth0Mgmt*` from repo secrets, but nothing in `src/` or `tests/` reads them; the app signs in with Azure AD B2C. The 11 `AUTH0_*` repo secrets can be deleted once this merges.
