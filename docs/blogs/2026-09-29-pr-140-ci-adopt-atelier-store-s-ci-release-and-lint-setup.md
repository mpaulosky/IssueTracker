# ci: Adopt atelier-store's CI, release and lint setup

- **Release tag:** `v0.0.1`
- **Source PR:** [#140](https://github.com/mpaulosky/IssueTracker/pull/140)

## PR description

### Summary

Brings IssueTracker onto atelier-store's hardened workflow baseline, adapted to this repo.

**CI**
- `ci.yml` replaces `test.yml` and `main-validation.yml`. It builds once, discovers test projects (`IsTestProject` only, so `TestingSupport.Library` is skipped), and runs them as a matrix. It also produces coverage (60% gate, as before) and ends with a **`Test Suite`** gate job.
- `IssueTracker.PlugIns.Tests.Unit` now runs in CI for the first time (37 tests, passing).
- The Auth0/Mongo secrets are scoped to the test job only. AppHost.Tests keeps its UI publish and its Docker pre-pull.
- Builds use `-warnaserror`, with documented `NoWarn` entries (CS0618/CS0067 until the bUnit `TestContext` migration, and ASPIRE010).

**Security and lint**
- Every action is pinned to a commit SHA, with `persist-credentials: false`.
- New `lint-actions.yml` runs actionlint, zizmor and shellcheck. CodeQL adds the `actions` language.
- One `.markdownlint-cli2.jsonc` replaces `.markdownlint.json` and `.markdownlintignore`, and one `.yamllint.yml` replaces `.yamllint`. Six docs were fixed to pass it. The legacy Copilot guidance is excluded until the follow-up PR rewrites it.
- `.github/hooks` (pre-commit Markdown lint, pre-push branch-name check plus `scripts/gate.sh`) runs the same checks locally. To set it up: `git config core.hooksPath .github/hooks`.

**Releases and automation**
- `release.yml` cuts a semver tag per merged PR (`semver:major`/`semver:minor` labels, patch by default) and opens a `[skip-release]` blog-post PR. `release_post.py` no longer creates `docs/README.md` in repos that don't publish one.
- `pr-automerge.yml` squash-merges same-repo PRs once the checks pass, Copilot has reviewed and all threads are resolved.
- `code-metrics.yml` keeps its push/PR triggers (IssueTracker has no primary constructors), opens its PR only from `main`, and marks it `[skip-release]`.
- Dependabot adds `dotnet-sdk` updates and keeps the Radzen/MessagePack/Testcontainers rules.
- Dropped: `docs.yml` (Pages builds `docs/` in legacy mode anyway), `.copilot/mcp-config.json`.

**SDK pin**
- `Global.json` → `global.json`: on Linux the SDK resolver only reads the lowercase name, so the pin was being ignored locally.
- Pinned to 10.0.300 with `rollForward: latestPatch`. **SDK 10.0.4xx fails to compile the Razor pages** (251 RZ/CS errors), so that upgrade needs its own PR.

### Before / after merge
