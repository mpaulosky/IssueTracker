# chore(sandcastle): Migrate to the Baseline Template's full pipeline

- **Release tag:** `v0.0.62`
- **Source PR:** [#279](https://github.com/mpaulosky/IssueTracker/pull/279)

## PR description

Closes #278.

Moves this repo's `.sandcastle/` from the older single-implementer pipeline onto the full one the repo-ci-baseline Template now owns (mpaulosky/dotfiles#280, mpaulosky/dotfiles#282).

- `apply.sh`: the Template's Owned files (the whole `.sandcastle/` pipeline and the other Owned drift: four workflows, `docs/PROCESS.md`, `global.json`) and the Seed role files, `pnpm-workspace.yaml` included.
- Taken from the Template by hand: `Dockerfile`, `plan-prompt.md`, `review-prompt.md`. Removed the old `implement-prompt.md` and the old pipeline's `check`, `publish` and `verdict` modules. `needs-docker.sh` stays, because `check.sh` uses it.
- `node` is now `tsx`, with `tsx` and `@standard-schema/spec` added, and `test:sandcastle` is now `check:sandcastle` everywhere it is called.
- Fixes the local run, which failed with `Cannot mount file to '.git/config'`.

`pnpm run check:sandcastle` passes and the pre-push gate passed.

Not done: this repo's own `CODING_STANDARDS.md` and `check.sh` are kept as they were.
