# build(deps): Pin the patched System.Security.Cryptography packages

- **Release tag:** `v0.0.55`
- **Source PR:** [#261](https://github.com/mpaulosky/IssueTracker/pull/261)

## PR description

### Why

Restore fails with NU1902/NU1903 because the vulnerable transitive versions of `System.Security.Cryptography.Pkcs` (10.0.10, 10.0.12) and `System.Security.Cryptography.Xml` (10.0.12) are covered by five .NET denial-of-service advisories: GHSA-2fmv-rv2c-59x7, GHSA-846f-f764-76mx, GHSA-7hqp-7c5m-4vq6, GHSA-c399-9853-6jmj and GHSA-r955-8q5j-3h83. Each one is first patched in 10.0.13. This failure is blocking the repo-ci-baseline reapply at the pre-push gate.

### What changed

- `Directory.Packages.props`: bump the `System.Security.Cryptography.Xml` override to 10.0.13, and add a `System.Security.Cryptography.Pkcs` 10.0.13 override. Transitive pinning is already on, so the override applies in every project. No new packages.

### Verification

- `dotnet restore IssueTracker.slnx` is clean.
- The pre-push gate passed: lint, Release build and every test project.
